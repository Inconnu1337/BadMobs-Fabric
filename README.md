# 🚫 BadMobs Port for Fabric 1.21.1

A simple mod which allows you to **disable the spawning for any entity in Minecraft**.  
To configure this mod, check your config folder for a `config/badmobs.json` file or use commands:
`/badmob set/save/reload` (need OP).

## ⚡ Features
- Blocks undesired mob spawns
- Fully compatible with Fabric mods
- Easy to configure through in-game config files
- Mod allows you to control **any mob spawn**. Here is a breakdown of the different spawn types:

| Spawn Type | Description |
|------------|-------------|
| **NATURAL** | Normal world spawning (darkness, grass, etc.) |
| **CHUNK_GENERATION** | Spawned when a new chunk is created |
| **SPAWNER** | Monster Spawner blocks |
| **STRUCTURE** | Spawned as part of a structure (Witch huts, etc.) |
| **BREEDING** | Animals falling in love |
| **MOB_SUMMONED** | Summoned by other mobs (Illagers, Vexes) |
| **JOCKEY** | Spider jockeys and similar |
| **EVENT** | Raids or special world events |
| **REINFORCEMENT** | Zombie reinforcements |
| **PATROL** | Illager patrols |
| **SPAWN_EGG** | Creative mode spawn eggs |
| **COMMAND** | Spawned via `/summon` or command blocks |
| **DISPENSER** | Spawned from a dispenser |
| **CONVERSION** | Zombie villagers curing, piglins turning to zombified |

Use these types in your `badmobs.json` to configure **precisely which mobs spawn and how**.
